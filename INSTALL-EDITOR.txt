物理部無線班｜編集画面の追加方法

1. ZIPを解凍します。
2. 中にあるファイルを、VSCodeで開いているサイトのフォルダーへ入れます。
   index.html、data.jsと同じ場所です。新しいフォルダーの中には入れません。
   script.jsは既存ファイルを置き換えます。
   もしscript.jsを自分で編集していた場合は、先にバックアップしてください。
   data.jsや写真はこのZIPに含まれていないため、今の展示内容はそのままです。
3. VSCodeのターミナルで次を1行ずつ実行します。

   git add admin.html admin.css admin.js admin-core.mjs script.js EDITOR.md admin-core.test.mjs INSTALL-EDITOR.txt
   git commit -m "Add exhibition editor"
   git push

4. 公開処理が終わったら次を開きます。
   https://butumu2027.github.io/Butumu2027/admin.html

5. 「GitHubに接続」→「初回の設定手順を見る」に従って認証キーを作成します。
   GitHubのログインアカウント：butumu2027
   対象リポジトリ：Butumu2027だけ
   必要な権限：Contents → Read and write
   認証キーは編集画面に入力してください。チャットには貼り付けません。

6. 作品や展示室を編集して「保存して公開」を押します。
   以降、この画面で編集するときはVSCodeでcommit/pushする必要はありません。

この編集画面でできること
・作品名、概要、仕組み、制作のポイントの編集
・写真の追加、キャプション、並べ替え、作品からの削除
・展示室の変更、表示順の変更、作品の追加と削除
・展示室の名前と画像の編集、追加と削除
・トップページのサイト名、コピー、紹介文、画像の編集
・下書きファイルの保存と再開
・GitHubへの一括保存とGitHub Pagesによる反映

注意
・画面を閉じる前に公開するか、下書きを保存してください。
・認証キーは画面を閉じると消えます。次回は同じキーで接続できます。
・別の場所で更新されているときは、上書きせずエラーを表示します。
・次にVSCodeで編集するときは、ローカルの変更を整理してから git pull --ff-only で最新にしてください。

検証状況
