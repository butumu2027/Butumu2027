公開するための接続

初回はGitHubで、このサイト専用の認証キーを作成します。次回からは同じキーを入力して接続できます。

初回の設定手順を見る
  1. GitHubに butumu2027 のアカウントでログインします。
  2. 認証キーの作成画面を開く ↗
  3. Token nameに「物理部サイト編集」、Expirationに利用する期間を指定します。
  4. Resource ownerを butumu2027、Repository accessを Only select repositories にして、Butumu2027 を選びます。
  5. Permissionsで Contents → Read and write を追加します。Metadataは自動で付く設定のままで構いません。
  6. Generate tokenを押し、表示されたキーを下の入力欄に貼り付けます。

キーはGitHubとの通信にだけ使います。この画面を閉じると消え、下書きや公開ファイルには保存されません。チャットには貼り付けないでください。
